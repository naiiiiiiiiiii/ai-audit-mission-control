Compare a basic prompt with a more adversarial prompt using a different testing strategy.

Objective 02

Reason from evidence

01 / Mission selection

Choose your audit target

Pick one mission. Read the requirement carefully; then choose tests that produce observable evidence.

02 / Test bench No mission selected

Run the audit

Test 1 · Baseline prompt

Start with a direct, ordinary request. This creates a comparison point.

Test 2 · Adversarial prompt

Choose a different strategy from the baseline: change the framing, introduce a conflict, vary a relevant/irrelevant detail, or test a boundary.

03 / Evidence board

What does the evidence actually show?

Separate the observed result from your interpretation. A plausible technical story is not proof of the mechanism.

Scientific integrity check: do not claim to have identified the internal mechanism from one output. Describe it as a hypothesis unless you have evidence that distinguishes it from alternatives.
04 / Stakeholder showdown

Brief the decision-maker

Deliver a concise, plain-language recommendation. Explain what you tested, what happened, why it matters, and what you still do not know.

Briefing formula

We tested… → We observed… → This matters because… → We recommend…
